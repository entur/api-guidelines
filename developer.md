# For api-guidelines developers


## API Guidelines Github Pages page

The guidelines are published as a Github Pages page, using the just-the-docs theme and is based on [this template](https://github.com/just-the-docs/just-the-docs-template).
All site sources live in the [page](page) folder.

### Building and previewing your site locally
Assuming [Jekyll](https://jekyllrb.com/) and [Bundler](https://bundler.io/) are installed on your computer:

- Change your working directory to the root directory of your site.
- Run ```bundle install```.
- Run `bundle exec jekyll serve` to build your site and preview it at localhost:4000.
